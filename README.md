図書館の貸し出しや蔵書の管理をするシステムです。
以下のライブラリを使用しております。
flask
flask_login
sqlite3
re
dotenv
os
flask_sqlalchemy
werkzeug.security
functools

sudachipy
math
sklearn.feature_extraction.text
ja_stopword_filter
numpy
pandas

実行方法
    python flaskmain.pyで起動してください
    ログインは利用者アカウントの場合はサインアップから
    管理者アカウントの場合はユーザー名"admin"パスワード"adminpass"
